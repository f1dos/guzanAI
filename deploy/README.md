# Focus на tokenapp.ru

Целевой VPS: `185.84.162.91`, Ubuntu/Debian, root для первичной установки.
В этой конфигурации публичный репозиторий скачивается сервером без GitHub-токена.

## Первая установка

В DNS домена задайте A `@ → 185.84.162.91`. Удалите другие A для корня.
AAAA можно оставить только при IPv6, который действительно ведёт на этот сервер.
Порты 80 и 443 должны быть доступны снаружи. Не создавайте www-запись, если www не нужен.

В SSH или веб-консоли Timeweb от root выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/f1dos/guzanAI/main/deploy/install.sh -o /root/focus-install.sh
bash /root/focus-install.sh
```

Установщик проверяет DNS и наличие существующего nginx-хоста tokenapp.ru.
Устанавливает отдельный Node.js 22 в `/opt/focus-node`, nginx, certbot, приложение и systemd-сервисы.
Не заменяет системный Node.js и не удаляет существующие сайты.
При запросе Google API key вставьте ключ: ввод скрыт. Он сохраняется только на VPS
в `/etc/focus/app.env` с правами 600. Если пропустить ключ, интерфейс работает,
а чат сообщает, что модель не настроена.

После успешной установки: **https://tokenapp.ru**.
Скрипт не содержит root-пароля, API-ключа или GitHub-токена.
При повторном запуске сохраняет ключ и существующую конфигурацию nginx/certbot.

## CI и автоматический деплой

Каждый push и pull request запускает GitHub Actions `Check Focus`:
проверка синтаксиса shell, тесты, сборка, валидация артефакта.
На VPS `focus-update.timer` раз в две минуты проверяет `main`.
Деплой разрешён только если **последний push-run ci.yml для точного SHA main** завершился success.
При ошибке GitHub API, failed/pending/cancelled CI сервер остаётся на текущей версии.
GitHub-токен и открытый webhook не нужны; публичного лимита API обычно достаточно
для одного сервера при проверке раз в две минуты.

Сервер дополнительно запускает тесты и сборку от отдельного пользователя `focus-build`.
Готовый релиз переносится в `/opt/focus/releases/<SHA>`, переключается ссылка `current`,
перезапускается `focus.service`. Проверяется `/healthz`, при неудаче возвращается предыдущий релиз.
Это короткий перезапуск, не zero-downtime. Предыдущие релизы сохраняются для отката;
со временем удаляйте старые, сохраняя текущий и предыдущий.
Первичная установка проверяет код локально и может стартовать до завершения первого CI.

Приложение работает от пользователя `focus`, слушает только `127.0.0.1:3000`.
Nginx обслуживает HTTPS и ограничивает частоту запросов к модели по IP.
Certbot автоматически продлевает сертификат. Пароль SSH в автодеплое не используется.
Обновление файлов deploy/ и системной конфигурации требует повторного запуска install.sh;
автодеплой обновляет только код приложения.

## Диагностика и ключ

```bash
systemctl status focus nginx focus-update.timer --no-pager
journalctl -u focus -n 80 --no-pager
journalctl -u focus-update -n 80 --no-pager
curl -fsS https://tokenapp.ru/healthz
curl -fsS https://tokenapp.ru/api/status
certbot renew --dry-run
```

Настройка или замена API-ключа:

```bash
sudoedit /etc/focus/app.env
systemctl restart focus
```

Проверить обновление сейчас: `systemctl start focus-update.service`.
Приостановить автодеплой: `systemctl stop focus-update.timer`.
Для ручного отката остановите таймер, измените `/opt/focus/current` на нужный
SHA из `/opt/focus/releases/` и выполните `systemctl restart focus`.

История, проекты и файлы пользователей пока хранятся в браузере. На публичном VPS нет
регистрации и общего доступа к истории; API чата доступен посетителям сайта с лимитом по IP.
Работа Google API из конкретного дата-центра должна быть проверена после установки.
Не передавайте ключ в URL или клиентские файлы.

## Бесплатный тест через OpenRouter

Если Google отклоняет регион сервера, можно подключить OpenRouter.
Приложение использует `openrouter/free` и не переключается на платные модели.
При наличии `OPENROUTER_API_KEY` этот провайдер имеет приоритет над Google.

После обновления приложения выполните от root:

```bash
curl -fsSL https://raw.githubusercontent.com/f1dos/guzanAI/main/deploy/connect-openrouter.sh -o /root/focus-openrouter.sh
bash /root/focus-openrouter.sh
```

Введите ключ в скрытом приглашении. Скрипт атомарно обновит `/etc/focus/app.env`
(права 600), перезапустит Focus и запустит проверку обновления.
Проверка `/api/status` должна вернуть `provider: openrouter`.
Затем отправьте сообщение через сайт: доступ из дата-центра и квоты проверяются реальным запросом.
Текстовые вложения и изображения передаются модели. Бинарный PDF в бесплатном режиме
не поддерживается: вставьте текст PDF или загрузите текстовый файл.
Модель выбирается роутером и может меняться; её фактический ID сохраняется с ответом.
Режим глубины ответа в этой конфигурации не применяется.

## Перенос на другой VPS (Германия)

Не меняйте DNS до подготовки приложения на новом VPS.
На новом сервере (109.120.176.117) выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/f1dos/guzanAI/main/deploy/install.sh -o /root/focus-install.sh
FOCUS_SERVER_IP=109.120.176.117 FOCUS_API_PROVIDER=openrouter FOCUS_PREPARE_ONLY=1 bash /root/focus-install.sh
```

Введите OpenRouter API key. Режим подготовки установит и проверит приложение локально,
но не будет выпускать сертификат и менять существующий nginx-хост.
Затем измените DNS A корня tokenapp.ru на 109.120.176.117. Проверьте также AAAA:
удалите старую запись или замените её на IPv6 нового сервера. Когда DNS обновится, выполните:

```bash
FOCUS_SERVER_IP=109.120.176.117 bash /root/focus-install.sh
```

Завершающий запуск сохранит ключ, настроит nginx/HTTPS и включит автодеплой.
Проверьте сайт и ответы модели с нового сервера перед отключением старого Focus.
Другие сайты на старом сервере переносить или останавливать не требуется.

## Если 443 занят Amnezia/Xray

Чтобы сохранить VPN без изменения клиентских подключений, Focus можно разместить на
`https://tokenapp.ru:8443`. После выпуска сертификата tokenapp.ru запустите
`deploy/alternate-port.py` от root. Скрипт меняет только Focus nginx-хост и PUBLIC_ORIGIN,
сохраняет закрытую резервную копию в /etc/focus/port-backups, проверяет nginx и локальный
HTTPS с проверкой сертификата. При неудаче возвращает прежние файлы. При успехе включает
таймер автодеплоя и продление сертификата. Docker-контейнеры и их настройки не меняются.
Разрешите TCP 8443 также во внешнем firewall хостинга, если он используется.
Скрипт добавляет правило UFW только если UFW уже включён. Порт 80 остаётся для ACME
и перенаправления на HTTPS 8443. Повторно запускать installer с certbot --redirect
без проверки конфигурации не следует: этот режим использует стандартный HTTPS-порт.


## Поиск в интернете (Tavily)

После успешного CI и обновления приложения выполните от root:

```bash
curl -fsSL https://raw.githubusercontent.com/f1dos/guzanAI/main/deploy/connect-search.sh -o /root/focus-search.sh
bash /root/focus-search.sh
```

Ключ вводится скрыто и сохраняется в /etc/focus/app.env с правами 600.
Скрипт не изменяет nginx, порт сайта или VPN. Проверяет реальный поиск с VPS
(1 кредит Tavily), не отправляя ключ в браузер и не выводя его.
Статус /api/status должен показать searchConfigured: true.
В интерфейсе включите «Поиск» и отправьте вопрос. Сначала показывается этап поиска,
затем источники и подготовка ответа. Источники и дата поиска сохраняются с ответом
в браузере, попадают в резервную копию и экспорт диалога. Поиск по умолчанию выключен.

Один запрос использует basic search, до 8 результатов, без raw_content и auto_parameters.
Модель получает только ограниченные выдержки. Плашки доменов и ссылки [1] ссылаются
на реальные результаты. Нельзя гарантировать, что модель подтвердит источниками
каждую фразу; пользователь должен проверять существенные утверждения по ссылкам.
При ошибке поиска не выдаётся ответ под видом найденного в интернете.

Защитные лимиты: 6 поисков/минуту на IP и 30/день на процесс по умолчанию.
Общий лимит меняется через TAVILY_DAILY_LIMIT в app.env с перезапуском focus.
Дневной счётчик хранится в памяти и сбрасывается при рестарте; жёсткое месячное
ограничение следует также установить в кабинете Tavily. Платное автопополнение
не настраивается. Снимок результатов привязан к IP, доступен 15 минут и хранится
только в памяти сервера (не более 250 снимков); при рестарте поиск нужно повторить.
